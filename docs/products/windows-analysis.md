# Windows-Analysis

Windows 호스트의 수집 증거를 파싱하고 침해사고 분석가의 통합 분석을 지원하는 프로그램이다.

## 목적

- Windows 호스트 분석
 - 빠르게 파싱한 데이터를 침해사고 분석가가 분석하는 방식에 맞게 뷰 구성
 - 해당 결과를 통합적으로 봐서 분석가가 놓치는 자료 없이 분석하기 위함
