# 호스트 연결 3D 뷰

2026-08-30 사용자와 확정한 규칙이다. 임의로 되돌리지 않는다.

- 그래프는 `react-force-graph-3d`(three.js) 기반이며 **물리 시뮬레이션 금지** —
  좌표는 해시 기반 결정적 고정 배치다. 같은 데이터는 항상 같은 자리에 놓인다.
- 이 뷰는 **성공 기록만** 다룬다. 결과(성공/실패) 필터는 두지 않는다.
- 보기 모드는 컨트롤 줄의 [보기] 드롭다운(검색 다음 위치) 2종이다.
  - 내부/외부 판별: 등록 호스트 간·같은 /24 대역·로컬/루프백에 더해
    **RFC1918 사설 IP(10/8, 172.16/12, 192.168/16)는 호스트 대역과 달라도
    내부로 취급**한다. 단 사설 대역은 망을 나눈 의도를 존중해 호스트 지형과
    병합하지 않고 별도 내부(파랑) 클러스터로 둔다 — 외부 뷰에도 내부로
    등장하고(선 없음), 내부 뷰에도 당연히 나온다.
  - **외부 호스트 뷰(기본):** 등록 호스트와 같은 /24 대역(미등록)을 네트워크별
    벌집 지형으로 합친다. 대역을 하나라도 공유하는 호스트는 union-find로 한
    지형, /24가 다르면(사무망/클라우드 등) 별개 지형이다. 내부 이동선(같은
    대역·호스트 간·루프백)은 그리지 않고, 로컬/127.0.0.1은 제외한다. 외부 상대
    1곳당 **대표선 1개**만 그린다(지형 내 여러 대상과 오갔어도 병합). 방향
    필터는 외부 상대·선에만 적용되고 내부 타일(지형)에는 영향을 주지 않는다.
  - **내부 호스트 뷰:** 전부 낱개 산개(벌집 묶음 금지)하고 내부 이동선만
    표기한다. 로컬/127.0.0.1을 포함하며, 로컬 타일은 소속 호스트와 같은 색으로
    호스트 곁에 배치한다. 색으로 구분하는 것은 등록 호스트뿐이고(호스트별 고유
    색), 그 외 노드는 단일 푸른색이다.
- 색 원칙: 등록 호스트 로즈(#e08a8a) / 같은 대역 미등록 푸른 계열 / 외부 미등록
  밝은 회색 계열. 선은 인바운드 #f2a86f · 아웃바운드 #9b7ef8 · 양방향 #5bc8c0
  (양방향은 한 단계 굵게). 호스트↔상대 쌍당 선은 1개이며 선은 타일 윗면 중심에
  닿는다.
- 하이라이트는 **호버 = 타일 클릭 고정(핀) = 목록 선택**이 모두 동일하다: 대상과
  연결된 타일·선만 남기고 나머지 타일은 흐리게, 관련 없는 선은 옅고 가늘게.
  타일 클릭은 핀으로 유지되고 재클릭·배경 클릭으로 해제되며, 보기 모드 전환 시
  선택·핀·호버는 초기화한다. 외부 뷰에서 같은 대역 타일 호버는 자기 자신만,
  등록 호스트 호버는 보이는 선이 있는 외부 상대만 강조한다.
- 정보 패널은 커서를 따라다니지 않고 **오른쪽 위 고정**이며 이름·대역·이벤트
  건수(+실패)만 표시한다(시각 표시 금지). 범례는 왼쪽 위 박스 패널 2줄(타일
  색/선 색)이다. 호스트 이름 상시 라벨, 타일 위 마커, 대역 상시 라벨, 하단 조작
  안내 문구는 두지 않는다 — IP·이름은 호버로 확인한다.
- 오른쪽 사이드는 상대(피어) 단위다. 목록 카드는 [IP]와 [인바운드 n건]
  [아웃바운드 n건]만 표시한다. 선택하면 **노드 중심 "연결한 호스트" 상세**로
  전환된다: 그 노드가 오간 상대 목록(등록 호스트는 칩 표시)과 방향·횟수 집계만
  보여 주고 개별 시각은 나열하지 않는다(시간은 원격 접근 이력 뷰의 몫). 상세도
  보기 모드의 내부/외부 기준을 따르고, 상대 행 클릭으로 드릴다운하며, "← 목록
  으로"로 복귀한다. 목록·상세 페이지네이션은 10건 고정이다.
