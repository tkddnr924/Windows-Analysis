# DFIR 분석 뷰

- 분석 화면에는 DFIR에 의미 있는 시간 정보를 우선 제공한다. 시간 정보가 없는
  아티팩트 레코드는 통합 타임라인에 포함하지 않는다.
- 통합 타임라인은 항상 시간 오름차순을 기본으로 하며, 사용자가 정렬을 전환할 수
  있다. 사고 기간 필터는 사이드바의 단일 전역 필터만 사용한다.
- EventLog의 실제 Event ID `0` 레코드는 원본 EventLog 뷰와 DB에는 보존하되, 반복적인
  상태성 로그가 시간축을 지배하지 않도록 통합 타임라인에서는 제외한다.
- 브라우저 타임라인은 캐시 응답만이 아니라 정규화된 방문·다운로드 기록도 같은
  시간축에 포함한다. 다운로드 위험 표시는 브라우저 Safe Browsing 원본 판정값과
  경로 기반 근거를 함께 보여 준다.
- 통합 타임라인 상단의 시간별 히스토그램·의미 없는 전체 건수 통계는 표시하지 않는다.
  필요한 제어는 정렬, 의심 항목, 아티팩트 필터로 제한한다.
- 대시보드는 실행한 파서와 해당 파서의 실제 추출 결과를 보여 준다. 전체 건수 중심의
  통계 카드나 중복된 원본 데이터 영역은 만들지 않는다. 파서 항목을 펼치면 입력 증거
  파일, 복구 적용 여부, 파일별 추출 건수를 보여 준다.
- 동일 아티팩트는 대시보드, 사이드바, 타임라인, 상세 보기에서 일관된 이름·색상·필드
  정의를 사용한다. 모든 상세 보기는 핵심 시간, 원본 경로, 관련 사용자/호스트,
  아티팩트별 DFIR 필드를 누락 없이 보여 준다.
- 북마크는 원본 증거 레코드를 기준으로 저장하고, 원본 EventLog에서 조합된 개요 뷰
  (PowerShellHistory 등)에서도 `record_key` 연결을 통해 같은 행 강조 상태로 표시한다.
- 북마크 상세의 대표 시각은 북마크 목록에서 선택한 시각을 그대로 전달한다.
  저장된 `eventTime`이나 선택 필드 시각을 원본 행의 `timestamp`·`last_write`에 덮어쓰지 않는다.
  UserAssist에서 승격된 북마크의 사건 시각과 Registry의 **레지스트리 키 마지막 기록 시각**은
  서로 다른 근거로 구분한다. 이 수정은 재파싱이나 북마크 데이터 마이그레이션을 요구하지 않는다.
- BrowserActivity 상세의 증거 개요는 `BrowserActivity:Visit`·`BrowserActivity:Download`·`BrowserActivity:Cache`와 접근 시간만 표시한다. 유형별 본문에는 URL 원본·디코딩 URL·계정 라벨을 공통으로 두고, 방문은 횟수, 다운로드는 경로·정확한 바이트·유형, 캐시는 유형·정확한 바이트·복구된 실제 본문을 표시한다. 캐시 본문을 복구하지 못했으면 `파싱 실패`로 명확히 남긴다.
- 모든 레코드 상세 보기는 공통 오른쪽 드로어(`RowDetailPanel`)로 연다. 개별 화면은
  상세 레이아웃을 독자 구현하지 않고 같은 레코드·아티팩트 정의를 이 공통 패널에
  전달한다. 아티팩트별 필드 개선은 공통 `artifactViews` 정의에서 수행한다.
- 상세 드로어 헤더는 제목과 실제 제어만 표시한다. 내부 구현 상태(예: 분석/원본 필드)는
  별도 문구로 노출하지 않으며, 전체 필드 전환·북마크 같은 제어는 앱의 표준 작은 반경을
  사용한다.
- AI 대화 뷰도 기간 필터와 페이지네이션을 적용하고, 기간 내 결과가 없으면 “기간 필터
  내 데이터 없음”을 표시한다.

## 분석 뷰 변경 검증

- 아티팩트 조건이 다른 레코드에 과적용되지 않았는지, 공통 상세 보기가 관련 뷰에서 같은지 확인한다.
- 2026-09-22: 실제 `RowDetailPanel`·`ArtifactDetailView`를 React 서버 렌더링한 임시 스모크에서
  북마크 사건 시각 `2026-05-16 09:00:00`이 수정 전에는 키 시각 `2026-05-19 12:00:00`으로
  표시되는 실패를 확인했다. 수정 후 사건 시각이 대표 시각이고 키 시각은 원본 필드에 유지됨을 확인했다.
  TypeScript 검사·기존 프런트엔드 테스트 16건 통과, 개발 앱 재실행·HTTP 200 확인.
  사용자 실 북마크는 로컬에 없어 같은 항목의 값 대조 및 Windows exe 실행은 미검증이다.
